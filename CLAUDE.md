# Claude Code instructions

## Git workflow

Always run `git pull --rebase` before pushing. A GitHub Actions workflow auto-commits README updates when plant files change, so the remote may have new commits after a push.

## Plant data accuracy

Never guess or estimate plant data (size, spacing, soil, water needs, etc.). If the information isn't already in the plant's markdown file and you don't have a citable source, ask the user rather than filling in a value. When adding data, cite the source in the plant file's Sources section.
